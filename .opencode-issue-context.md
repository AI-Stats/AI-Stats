# Issue thread snapshot

Issue: #1563 Improve Models filters and provider parity on mobile
Opened by: @DanielButler1

## Original issue body

## Problem
The Models experience does not provide the same practical filtering capability on mobile as on larger screens.

## Acceptance criteria
- Relevant model and provider filters are accessible on mobile.
- Active filters are visible and can be cleared.
- Opening and closing controls preserves selections.
- Results match equivalent desktop filtering.
- Controls do not overflow narrow viewports.
