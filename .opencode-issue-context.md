# Issue thread snapshot

Issue: #1578 Test and fix model selection on dynamic routes
Opened by: @DanielButler1

## Original issue body

## Problem
Model selection can become inconsistent with the page's dynamic route.

## Acceptance criteria
- Direct navigation selects the route's model.
- Changing the dropdown updates route or state as intended.
- Back and forward navigation restore the correct selection.
- Invalid or unavailable values have a clear fallback.
- Tests cover direct and client-side navigation.
