# Issue thread snapshot

Issue: #1618 [Feature] Add contextual selection actions to /chat
Opened by: @DanielButler1

## Original issue body

## Summary

Add a contextual action toolbar to the `/chat` route when a user selects text in an assistant response.

The toolbar should visually highlight the selected text and appear beneath the final selected line, inspired by the provided `SelectionActions` component from Beautiful UI. It should offer quick actions such as:

- Explain
- Improve
- Shorten
- Change tone
- Fix grammar
- Custom instruction

When a user presses an action, insert a relevant prompt into the existing chat composer that references the selected text and describes the requested operation. The user should be able to review or edit the prompt before submitting it. The available actions can be adjusted to fit the existing chat experience and supported prompt behavior.

## Acceptance criteria

- Selecting text in an assistant message applies a clear selection highlight.
- A contextual toolbar appears near the selected text and remains correctly positioned across multiline selections.
- The toolbar is responsive and does not overflow the viewport.
- The toolbar includes a concise set of useful quick actions, with an expandable option for additional actions if appropriate.
- Selecting an action inserts a relevant prompt into the existing chat composer.
- The selected text is included in the generated prompt or otherwise clearly associated with the action.
- Users can edit the generated prompt before sending it.
- Submitting the prompt uses the existing chat request flow.
- The toolbar supports loading, success/replacement, retry, and dismiss states where the action immediately triggers an AI rewrite.
- Users can dismiss the toolbar by clicking elsewhere, changing the selection, or clearing the selection.
- Keyboard and screen-reader interactions are supported, including accessible labels and focus states.
- The behavior works for assistant responses containing multiple paragraphs and multiline text.
- Add targeted tests covering selection detection, action-to-prompt mapping, dismissal, and responsive positioning.
