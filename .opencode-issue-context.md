# Issue thread snapshot

Issue: #1577 Attach session IDs to chat conversations
Opened by: @DanielButler1

## Original issue body

## Problem
Chat conversations under `/chat` need a stable session identifier so related messages and requests can be associated reliably.

## Acceptance criteria
- Each conversation receives a stable session ID.
- Subsequent messages retain it; new conversations receive distinct IDs.
- The server request path and relevant logs or traces receive the ID.
- Compatibility behavior exists for current chats and direct API callers.
- Tests cover creation and reuse.
