Use this page to find the correct API path before opening an endpoint reference. All Phaseo Gateway endpoints share one base URL and use bearer authentication.

## Choose your path

| If you want to | Start with |
| --- | --- |
| Send your first request | [Quickstart](../quickstart) |
| Generate text or use tools | [`POST /responses`](./endpoint/responses) |
| Keep an existing OpenAI-compatible integration | [`POST /chat/completions`](./endpoint/chat-completions) |
| Browse models and providers | [`GET /models`](./endpoint/models) and [`GET /providers`](./endpoint/providers) |
| Create music or manage files | [`POST /music/generations`](./endpoint/music-generate) and [`POST /files`](./endpoint/files) |

## Base URL

Production base URL:

```http
https://api.phaseo.app/v1
```

All endpoint paths in this reference are relative to that `/v1` base URL.

## Authentication

Most endpoints require a standard gateway API key. Management endpoints require a management API key created in the dashboard.

```http
Authorization: Bearer phaseo_v1_sk_<kid>_<secret>
```

If authentication fails, the API returns `401`.

## API resources

| Resource | What it does |
| --- | --- |
| Responses API | Generate model responses with tools, structured output, and multimodal input. |
| Chat Completions | Keep an existing OpenAI-compatible chat integration. |
| Anthropic Messages | Keep an Anthropic-compatible Messages integration. |
| Embeddings | Create vector representations for search, retrieval, and classification. |
| Images | Generate or edit images. |
| Text-to-Speech | Generate spoken audio from text. |
| Speech-to-Text | Transcribe or translate audio. |
| Music Generation | Create music jobs and inspect their status. |
| Files | Upload and retrieve inputs for supported API workflows. |
| Models, Providers, and Endpoints | Discover what is available through the Gateway. |
| Pricing, Activity, and Generations | Estimate cost and inspect request outcomes. |
| API Keys and Workspaces | Manage programmatic access and workspace resources. |

## Billing and rate limits

- Phaseo does not apply its own rate limits. Limits are enforced by upstream providers.
- Paid requests require enough wallet balance to pass the preflight credit check.
- Free models with `:free` do not require deposited credits.
