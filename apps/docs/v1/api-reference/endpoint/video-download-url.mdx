---
title: "Create a video download URL"
sidebarTitle: "Create a download URL"
tag: "Internal"
openapi: "POST /videos/{video_id}/download_url"
description: |-
  <Info>
  **Internal testing.** The Video API is available only to enabled workspaces and may be temporarily disabled while its public contract is finalised. The API may change before general availability.
  </Info>

  Issue a temporary signed download URL for a completed video generation.
---

Optional request fields let you choose:

- `ttl_seconds` for link lifetime
- `disposition` as `attachment` or `inline`
- `index` when a generation has multiple outputs

The response returns:

- `download_url`
- `expires_at`
