Requests cancellation for a non-terminal video generation job.

Cancellation is provider-dependent. If the selected provider does not support it, Phaseo returns a structured `501 not_implemented_yet` response. Completed, failed, cancelled, and expired jobs are already terminal and are not cancelled again.
