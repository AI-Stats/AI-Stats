---
title: "Replace dynamic-route keys"
sidebarTitle: "Attach keys"
badge: "Beta"
openapi: "PUT /routing/dynamic-routes/{id}/keys"
description: "Atomically replace the API keys attached to a dynamic route."
---
<Note>This endpoint requires a management API key with `settings:write`.</Note>

All keys must belong to the management key workspace. A key can be attached to only one dynamic route.
