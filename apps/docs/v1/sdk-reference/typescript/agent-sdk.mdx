Use this guide to run a TypeScript agent that can call a local tool and return a final answer. You will define one tool, connect the agent to Phaseo Gateway, and run the complete tool loop.

## Install

```bash
pnpm add @phaseo/sdk @phaseo/agent-sdk
```

## Create a tool

Define tools with a stable ID, a clear description, and a JSON schema for the arguments the model can supply.

```typescript
import {
  createAgent,
  createGatewayAgentClient,
  defineTool,
} from "@phaseo/agent-sdk";

const lookupDocs = defineTool({
  id: "lookup-docs",
  description: "Look up a Phaseo documentation page by slug.",
  parameters: {
    type: "object",
    properties: {
      slug: { type: "string" },
    },
    required: ["slug"],
    additionalProperties: false,
  },
  async execute(input: { slug: string }) {
    return {
      slug: input.slug,
      url: `https://phaseo.app/docs/v1/${input.slug}`,
    };
  },
});
```

## Run the agent

Keep the first agent narrow: one workflow and one or two tools is usually enough.

```typescript
const agent = createAgent({
  id: "support-docs-agent",
  model: "phaseo/free",
  instructions: "Use tools when helpful and finish with a concise answer.",
  tools: [lookupDocs],
});

const result = await agent.run({
  input: "Find the docs page for presets and explain when to use them.",
  client: createGatewayAgentClient({
    clientOptions: {
      apiKey: process.env.PHASEO_API_KEY!,
    },
  }),
});

console.log(result.output);
```

The runtime sends the current messages to the model, executes returned local tool calls, appends their results, and continues until it reaches a final answer or a configured stop condition.
