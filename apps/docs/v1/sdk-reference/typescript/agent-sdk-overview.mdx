The TypeScript Agent SDK defines the shared runtime contract implemented across the supported Agent SDK languages. Use it for typed tools, async streaming, approvals, dynamic turns, and application-owned resumability.

## Native runtime model

- Async generators publish tool progress and return a final result.
- Replayable async streams expose text, reasoning, items, tools, and full events.
- Runtime schemas validate tool inputs, outputs, progress, and final output.
- `AbortSignal` carries cancellation and timeout signals into local tools.
- Async state accessors load and save complete run results through your storage layer.

## Core capabilities

| Area | TypeScript API |
| --- | --- |
| Agents and tools | `createAgent(...)`, `defineTool(...)` |
| Gateway execution | `createGatewayAgentClient(...)` |
| Continuation | `continueRun(...)`, exact-ID decisions, and manual outputs |
| Streaming | `stream(...)` with replayable text, reasoning, item, tool, and full streams |
| Control | retries, cancellation, timeouts, concurrency, stop conditions, and dynamic turns |
| Observability | typed lifecycle events, normalized usage/cost, and Phaseo Devtools |

TypeScript is the API design reference, but Python, Go, C#, Java, PHP, and Ruby implement the same core behavior using their native runtime primitives.
