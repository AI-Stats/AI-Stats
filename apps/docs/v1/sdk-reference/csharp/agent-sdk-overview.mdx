The C# Agent SDK is a full local runtime for Phaseo Gateway. It uses tasks, cancellation tokens, async enumerables, delegates, and application-owned state interfaces.

## Native runtime model

- Tasks execute model turns and local tools without blocking application threads.
- `CancellationToken` and tool timeouts stop work cleanly.
- Replayable async enumerables expose model text and lifecycle events.
- Validation and approval delegates keep tool boundaries explicit.
- `IStateAccessor` loads and saves run results through your own storage layer.

## Core capabilities

| Area | C# API |
| --- | --- |
| Agents and tools | `AgentSdk.CreateAgent(...)`, `AgentSdk.DefineTool(...)`, `Tool` |
| Gateway execution | `AgentSdk.CreateGatewayAgentClient(...)` |
| Continuation | `Agent.ContinueRun(...)`, exact-ID decisions, and manual outputs |
| Streaming | `Agent.Stream(...)`, `TextStream()`, `FullStream()`, and `GetResult()` |
| Control | retries, cancellation, timeouts, concurrency, stop conditions, and dynamic turns |
| Observability | event delegates, normalized usage/cost, and Phaseo Devtools |
