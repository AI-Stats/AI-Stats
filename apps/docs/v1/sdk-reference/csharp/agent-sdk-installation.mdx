## Requirements

- .NET 8 or newer
- a Phaseo API key

## Install

```bash
dotnet add package Phaseo.Sdk
dotnet add package Phaseo.AgentSdk
```

## Environment

Set your gateway API key before running examples:

```bash
set PHASEO_API_KEY=phaseo_v1_sk_...
```
