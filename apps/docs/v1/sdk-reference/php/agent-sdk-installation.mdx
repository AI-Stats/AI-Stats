## Requirements

- PHP 8.1 or newer
- Composer
- a Phaseo API key

## Install

```bash
composer require phaseo/sdk phaseo/agent-sdk
```

## Environment

Set your gateway API key before running examples:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
