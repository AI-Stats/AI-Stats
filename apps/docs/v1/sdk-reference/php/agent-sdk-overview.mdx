The PHP Agent SDK is a full local agent state machine for Phaseo Gateway. It uses synchronous callbacks and iteration while retaining the same approval, streaming, stop, state, and usage contract as the other Agent SDKs.

## Native runtime model

- Tool callbacks execute synchronously in the standard PHP runtime.
- Callables validate tool inputs, outputs, progress events, and final output.
- Iterables expose replayable text, reasoning, item, and full-event streams.
- Exact tool-call IDs make approvals, rejections, and manual outputs safe to resume.
- `StateAccessor` loads and saves run results through your own storage layer.

## Core capabilities

| Area | PHP API |
| --- | --- |
| Agents and tools | `AgentSdk::createAgent(...)`, `AgentSdk::defineTool(...)`, `Tool` |
| Gateway execution | `AgentSdk::createGatewayAgentClient(...)` |
| Continuation | `continueRun(...)`, `continueRunById(...)`, and manual outputs |
| Streaming | `stream(...)`, `textStream()`, `reasoningStream()`, and `fullStream()` |
| Control | retries, timeout checks, stop predicates, dynamic turns, and tool-error policy |
| Observability | event callbacks, normalized usage/cost, and Phaseo Devtools |
