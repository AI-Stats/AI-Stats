title: "Stop conditions"
description: "Bound Java agent work by steps, tokens, cost, duration, tools, or finish reason."
---

Compose stop helpers in `AgentDefinition.stopWhen`:

```java
var stopWhen = List.of(
    AgentSdk.stepCountIs(12),
    AgentSdk.maxTokensUsed(40_000),
    AgentSdk.maxCost(2),
    AgentSdk.maxDuration(Duration.ofMinutes(1))
);
```

Additional helpers include `hasToolCall(...)` and `finishReasonIs(...)`. The first matching condition records a stop reason and returns a stopped run rather than silently continuing.

Use cost and token limits only when the selected model route reports that information. Always keep a step or duration limit as a fallback execution bound.
