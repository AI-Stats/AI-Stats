description: "React to Java run, model, step, tool, and checkpoint events."
---

Pass an event consumer in `RunOptions` to connect an agent to a product timeline, audit log, or telemetry pipeline:

```java
event -> logger.info("{} {}", event.type(), event.runId())
```

Event families cover:

- run start, resume, human wait, completion, cancellation, and failure
- step start, checkpoint, completion, cancellation, and failure
- model request, completion, and failure
- tool start, preliminary progress, completion, and failure

Keep the callback fast. Queue slow storage or network work outside the runtime loop.
