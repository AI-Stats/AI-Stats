title: "Dynamic turns"
description: "Change Java model settings and tools between agent turns."
---

Use dynamic callbacks when later turns should respond to application context, earlier tool results, or the number of completed turns.

Dynamic values can select:

- model or fallback models
- instructions
- temperature, top-p, and maximum output tokens
- the tool list for the next model request

Tools can update application context through `RuntimeContext` and can return `NextTurnParams` for the immediately following request. Next-turn overrides are persisted with paused state, so approval does not discard a tool's routing or sampling decision.

Keep context and next-turn values serializable when the run may be loaded through `StateAccessor`.
