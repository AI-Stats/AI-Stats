## Requirements

- Python 3.10 or newer
- a Phaseo API key

## Install

```bash
pip install phaseo phaseo-agent-sdk
```

## Environment

Set your gateway API key before running examples:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
