The Python Agent SDK is a full local runtime for Phaseo Gateway. Use it to run multi-step tools, stream model output, pause for decisions, and resume work from state stored by your application.

## Native runtime model

- Python iterators expose replayable text, reasoning, item, tool, and full-event streams.
- Callable schemas validate tool inputs, outputs, progress events, and final output.
- Bounded worker threads execute independent tools concurrently while preserving tool-result order.
- Callbacks handle progress, lifecycle events, approvals, and mutable application context.
- `AgentStateAccessor` loads and saves serializable run results without a hosted state service.

## Core capabilities

| Area | Python API |
| --- | --- |
| Agents and tools | `create_agent(...)`, `define_tool(...)`, `AgentTool` |
| Gateway execution | `create_gateway_agent_client(...)` |
| Continuation | `continue_run(...)`, exact-ID approvals, rejections, and manual outputs |
| Streaming | `stream(...)` with replayable iterator consumers |
| Control | retries, timeouts, concurrency, stop predicates, and dynamic turns |
| Observability | lifecycle callbacks, normalized usage/cost, and Phaseo Devtools |
