Use this guide to run a Python agent while keeping tools and state inside your application.

```python
import os

from phaseo_agent import create_agent, create_gateway_agent_client

client = create_gateway_agent_client(
    client_options={"api_key": os.environ["PHASEO_API_KEY"]}
)

agent = create_agent({
    "id": "quickstart-agent",
    "model": "openai/gpt-5.4-nano",
    "instructions": "Answer concisely and helpfully.",
})

result = agent.run(input="Give me one fun fact about cURL.", client=client)
print(result.output)
```
