The Go Agent SDK is a full local runtime for Phaseo Gateway. It combines explicit run state with contexts, goroutine-backed tools, channels, and application-owned persistence.

## Native runtime model

- `context.Context` carries cancellation and timeout signals through model and tool work.
- Bounded goroutines execute independent tools concurrently while preserving tool-result order.
- Channels expose replayable model text and lifecycle events.
- Validators and approval predicates keep tool boundaries explicit.
- `StateAccessor` loads and saves run results through your own storage layer.

## Core capabilities

| Area | Go API |
| --- | --- |
| Agents and tools | `CreateAgent(...)`, `DefineTool(...)`, `Tool` |
| Gateway execution | `CreateGatewayAgentClient(...)` |
| Continuation | `Agent.Continue(...)`, exact-ID decisions, and manual outputs |
| Streaming | `Agent.Stream(...)`, `Text()`, `Events()`, and `Result()` |
| Control | retries, contexts, timeouts, concurrency, stop conditions, and dynamic turns |
| Observability | event handlers, normalized usage/cost, and Phaseo Devtools |
