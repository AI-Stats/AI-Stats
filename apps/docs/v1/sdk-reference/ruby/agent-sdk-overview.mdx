The Ruby Agent SDK is a full local runtime for Phaseo Gateway. It uses enumerators, thread-backed tools, callback validation, and duck-typed state accessors.

## Native runtime model

- Bounded threads execute independent tools concurrently while preserving tool-result order.
- Enumerators expose replayable text, reasoning, item, and full-event streams.
- Callbacks validate tool boundaries, approvals, progress events, and final output.
- Exact tool-call IDs make approvals, rejections, and manual outputs safe to resume.
- Any object with compatible `load` and `save` methods can own run persistence.

## Core capabilities

| Area | Ruby API |
| --- | --- |
| Agents and tools | `PhaseoAgentSdk.create_agent`, `define_tool`, and `Tool` |
| Gateway execution | `create_gateway_agent_client` |
| Continuation | `Agent#continue_run`, exact-ID decisions, and manual outputs |
| Streaming | `Agent#stream`, `text_stream`, `reasoning_stream`, and `full_stream` |
| Control | retries, timeouts, concurrency, stop predicates, and dynamic turns |
| Observability | event callbacks, normalized usage/cost, and Phaseo Devtools |
