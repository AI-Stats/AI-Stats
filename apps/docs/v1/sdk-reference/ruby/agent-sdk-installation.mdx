## Requirements

- Ruby 3.2 or newer
- RubyGems or Bundler
- a Phaseo API key

## Install

```bash
gem install phaseo_sdk phaseo_agent_sdk
```

## Environment

Set your gateway API key before running examples:

```bash
export PHASEO_API_KEY="phaseo_v1_sk_..."
```
